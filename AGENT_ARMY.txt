2. DOES PORTFOLIO AGENT NEED AN LLM?
================================================================================

ANSWER: NO.

Portfolio Construction Agent = DETERMINISTIC CODE / OPTIMIZATION.
  Inputs  : promoted signal scores, risk budgets, lot sizes, cash, constraints
  Process : mean-variance / risk-parity-lite / score→weight with hard caps
  Output  : draft target weights / lots (proposal only)

Why no LLM:
  - Weights must be reproducible, auditable, unit-testable
  - SEBI/broker/audit trail needs deterministic sizing math
  - LLM “feels like reduce Reliance 2%” is not a desk

LLM MAY help only at BUILD-TIME:
  Cursor writes the portfolio optimizer code + tests.
  At RUN-TIME the optimizer is pure Python/numpy — zero LLM calls.
